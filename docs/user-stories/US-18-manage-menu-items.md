| Field | Value |

| Priority | Must |
| Estimate | 5 SP |

## Story

**As a** manager, **I want** to create and edit menu items, **so that** the digital menu is complete and accurate.

## Acceptance Criteria

1. Fields: name and description (vi/en), price (VND), photo, category, kitchen station, tags (best seller, spicy, vegetarian, new), allergens, active flag.
2. Price changes apply only to new orders (BR-6).
3. Items can be reordered within a category and duplicated.
