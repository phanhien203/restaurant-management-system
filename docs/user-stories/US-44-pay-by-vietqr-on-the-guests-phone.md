# US-44 Pay by VietQR on the guest's phone

| Field | Value |

| Priority | Should |
| Estimate | 2 SP |

## Story

**As a** guest, **I want** to see the VietQR on my phone, **so that** I can transfer without waiting for a printed bill.

## Acceptance Criteria

1. After a bill request, the guest page shows the total, bill code and VietQR (amount and code pre-filled).
2. The page updates to "Paid" when the cashier confirms.
