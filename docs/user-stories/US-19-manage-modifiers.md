# US-19 Manage modifiers

| Field | Value |
|---|---|
| Epic | EP-02 Menu |
| Priority | Must |
| Estimate | 5 SP |
| Depends on | [US-18](US-18-manage-menu-items.md) |

## Story

**As a** manager, **I want** modifier groups on items, **so that** guests can choose size, doneness, spice and extras.

## Acceptance Criteria

1. Modifier group: name (vi/en), single or multiple choice, required flag, min/max selections.
2. Each option has a name and a price delta (≥ 0).
3. A group can be reused across items; order of groups and options is configurable.
