# US-14 Manage staff accounts

| Field | Value |
|---|---|
| Epic | EP-01 Access & Administration |
| Priority | Must |
| Estimate | 3 SP |
| Depends on | [US-13](US-13-staff-login.md) |

## Story

**As a** Tenant Admin, **I want** to create and manage staff accounts, **so that** each person has the right access.

## Acceptance Criteria

1. Create, edit, deactivate staff; assign one branch and one or more roles: Manager, Waiter, Kitchen, Cashier.
2. Kitchen staff are assigned to one or more stations.
3. Admin can reset a password (forces change on next login).
