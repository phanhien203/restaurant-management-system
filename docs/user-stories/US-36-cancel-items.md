# US-36 Cancel items

| Field | Value |
|---|---|
| Epic | EP-05 Waiter App |
| Priority | Must |
| Estimate | 3 SP |
| Depends on | [US-33](US-33-confirm-or-reject-qr-orders.md) |

## Story

**As a** waiter, **I want** to cancel ordered items with a reason, **so that** the bill and kitchen stay correct.

## Acceptance Criteria

1. Guests cannot cancel confirmed items (BR-3).
2. Waiter cancels Confirmed (not yet preparing) items with a reason; Preparing/Ready items need a manager PIN/approval.
3. Cancelled items are removed from KDS and the bill; all cancellations are audited.
