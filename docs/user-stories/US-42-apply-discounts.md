# US-42 Apply discounts

| Field | Value |
|---|---|
| Epic | EP-07 Billing & Payment |
| Priority | Must |
| Estimate | 3 SP |
| Depends on | [US-41](US-41-view-bill-and-print-pre-bill.md), [US-15](US-15-role-based-permissions.md) |

## Story

**As a** manager, **I want** to apply a discount to an item or the bill, **so that** I can handle complaints and promotions.

## Acceptance Criteria

1. Percentage or fixed amount; mandatory reason; only roles with permission.
2. Discount cannot make a line or the bill negative; audited (BR-7).
