## Story

**As a** cashier, **I want** to export invoice requests, **so that** I can issue e-invoices in our current e-invoice tool.

## Acceptance Criteria

1. Filter by date; export CSV/Excel with bill code, date, buyer details, line items, VAT and totals.
2. Each request can be marked "issued".
