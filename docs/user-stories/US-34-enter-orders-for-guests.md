# US-34 Enter orders for guests

| Field | Value |
|---|---|
| Epic | EP-05 Waiter App |
| Priority | Must |
| Estimate | 3 SP |
| Depends on | [US-30](US-30-live-floor-plan.md), [US-19](US-19-manage-modifiers.md) |

## Story

**As a** waiter, **I want** to enter orders on my device, **so that** guests who don't use QR are served too.

## Acceptance Criteria

1. Same menu, modifiers and notes as the guest app, optimised for speed (search, recent items).
2. Waiter orders are confirmed on submit and go straight to KDS as a new round.
