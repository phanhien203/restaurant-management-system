## Story

**As a** manager, **I want** to set up zones and tables, **so that** the floor plan matches the restaurant.

## Acceptance Criteria

1. Create, rename, reorder and deactivate zones and tables; table has a name/number and capacity.
2. A table with an open session cannot be deleted.
