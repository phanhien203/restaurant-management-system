## Story

**As a** guest, **I want** to browse categories with photos and prices, **so that** I can choose quickly.

## Acceptance Criteria

1. Category tabs, item cards (photo, name, price, tags), search by name.
2. Sold-out items greyed out; availability updates live.
3. Language switch vi/en; restaurant branding applied.
4. First meaningful paint ≤ 3 s on simulated 4G (Lighthouse mobile).
