# US-17 Manage categories

| Field | Value |
|---|---|
| Epic | EP-02 Menu |
| Priority | Must |
| Estimate | 2 SP |
| Depends on | [US-15](US-15-role-based-permissions.md) |

## Story

**As a** manager, **I want** to manage menu categories, **so that** guests find items easily.

## Acceptance Criteria

1. Create, rename (vi/en), reorder (drag and drop), hide/show, delete empty categories.
2. Changes appear on the guest menu without redeploy.
