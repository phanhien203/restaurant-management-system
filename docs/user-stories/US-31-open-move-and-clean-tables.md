# US-31 Open, move and clean tables

| Field | Value |
|---|---|
| Epic | EP-05 Waiter App |
| Priority | Must |
| Estimate | 3 SP |
| Depends on | [US-30](US-30-live-floor-plan.md) |

## Story

**As a** waiter, **I want** to manage the table lifecycle, **so that** table status reflects reality.

## Acceptance Criteria

1. Open a session manually with guest count (for guests not using QR).
2. Move a session (all rounds and the bill) to another empty table.
3. Mark a *Cleaning* table as *Empty*.
