# US-29 Call waiter and request the bill

| Field | Value |
|---|---|
| Epic | EP-04 Guest QR Ordering |
| Priority | Must |
| Estimate | 2 SP |
| Depends on | [US-23](US-23-scan-qr-and-join-the-table-session.md) |

## Story

**As a** guest, **I want** to call a waiter or request the bill from my phone, **so that** I don't have to wave for attention.

## Acceptance Criteria

1. "Call waiter" with optional reason (water, cutlery, other); "Request bill" sets the table to *Bill requested*.
2. Repeat requests within 60 s are ignored; the guest sees the request was sent.
