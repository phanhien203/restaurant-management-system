# US-35 Mark items served

| Field | Value |
|---|---|
| Epic | EP-05 Waiter App |
| Priority | Must |
| Estimate | 2 SP |
| Depends on | [US-38](US-38-update-item-status-and-timers.md) |

## Story

**As a** waiter, **I want** to mark ready items as served, **so that** the kitchen and guests know they're delivered.

## Acceptance Criteria

1. Ready items are highlighted per table; mark one or all as Served.
2. When all items are served, the table leaves *Waiting for food*.
